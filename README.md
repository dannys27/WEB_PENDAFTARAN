# 🏫 Sistem Pendaftaran Siswa Baru (PPDB) - SDN Kampung Bulak 4

Sistem informasi berbasis web yang dirancang untuk memudahkan proses pendaftaran calon siswa baru secara mandiri dan pengelolaan data pendaftar oleh admin sekolah.

## ✨ Fitur Utama
- **Formulir Pendaftaran Modern**: Tampilan responsif menggunakan CSS Grid dan Font Poppins untuk kenyamanan pengguna.
- **Bukti Pendaftaran Otomatis**: Setelah mendaftar, orang tua bisa langsung mencetak bukti pendaftaran yang rapi.
- **Dashboard Admin**: Admin dapat memantau total pendaftar, jumlah siswa laki-laki, dan perempuan secara real-time.
- **Manajemen Data (CRUD)**: Admin memiliki akses penuh untuk menambah, melihat, mengedit, dan menghapus data calon siswa.
- **Laporan Cetak**: Fitur untuk mencetak laporan seluruh daftar pendaftar dalam format yang siap cetak.

## 🚀 Teknologi yang Digunakan
- **PHP**: Bahasa pemrograman backend.
- **MySQL**: Penyimpanan database pendaftar.
- **CSS3 (Modern UI)**: Menggunakan Flexbox, Grid, dan Google Fonts (Poppins).
- **JavaScript**: Untuk interaksi sederhana dan fitur cetak dokumen.
